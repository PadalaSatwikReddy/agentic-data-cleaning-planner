Agentic Data Cleaning Methodology

Autonomous, test-driven, loss-aware architecture

1. How Information Loss Is Calculated

Unlike tools that automatically purge rows, Clean Agent quantifies the penalty of every candidate operation based on records removed, variance distortion, and broken relational dependencies. It recommends conservative strategies like group median imputation over destructive deletion.

2. Invariant vs Boundary Constraints

Hard invariants (e.g. Employee_ID uniqueness, non-negative monetary amounts) are strictly enforced. Soft constraints (e.g. high salaries) are flagged for human inspection rather than deleted as outliers.

3. Automated Test Synthesis

Inspired by Great Expectations, Clean Agent auto-generates unit assertions covering domain integrity, record count preservation, and sparsity contracts.
